The repository forensic audit classifies the current benchmark as NOT YET TRUSTWORTHY as a fully unit-consistent QSAR benchmark. 06 · EXPERIMENTAL DESIGN

Scaffold-aware evaluation

The repository groups molecules by Bemis–Murcko scaffold and assigns whole scaffold groups to partitions. The forensic audit identifies the actual implementation as a deterministic size-sorted greedy scaffold split, not a random scaffold split.

10 · SCIENTIFIC AUDIT

What the forensic audit says

The repository contains an explicit forensic audit of the pipeline and saved dataset. Its overall verdict is “C. NOT YET TRUSTWORTHY.” That conclusion is retained here because it is part of the project evidence.

Critical

Unit-inconsistent potency threshold

The code applies standard_value <= 10000 rather than applying the threshold to normalized IC50.

High

Deterministic scaffold allocation

The split is size-sorted and greedy; it should be described as such rather than as a random scaffold split.

Medium

Duplicate aggregation order

Median pIC50 is computed before later relation and potency filtering, making target construction cohort-dependent.

Low

Unused random split helper

A random split helper exists in the code but is not used in the current reported model path.

What the audit did verify: the pIC50 formula is mathematically correct; the current scaffold split has zero scaffold and molecule overlap; and Optuna is isolated from the held-out test set through scaffold-grouped CV.
11 · LIMITATIONS

Interpretation boundaries

  • The benchmark should be interpreted as a scaffold-extrapolation estimate under the implemented deterministic split, not as a generic statement of QSAR generalization.
  • The potency threshold should be applied to normalized IC50 for physical unit consistency.
  • The exact dataset snapshot and software environment matter for reproducibility.
  • The repository audit recommends correcting the thresholding issue before treating the benchmark as a clean, publication-ready estimate.
