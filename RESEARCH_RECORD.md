# Research Record

## Project

**AChE Molecular Machine Learning: Structure-Aware Prediction of
Acetylcholinesterase Inhibitory Potency**

**Author:** Darshan Venkataramanan

**Repository:**  
https://github.com/TheHashiramaSenju/AcHe-QSAR-modelling

## Versioned research snapshot

This repository contains a versioned research record of the AChE molecular
machine-learning project.

The `v1.0.0` release represents the state of the repository designated by the
author as the first formal research release.

The release includes the documented implementation, experimental outputs,
diagnostic analyses, audit artifacts, and scientific report available in the
repository at the time of release.

## Scope of the documented work

The research workflow includes:

1. ChEMBL activity-data retrieval
2. AChE target selection
3. Molecular structure processing
4. Activity-value normalization
5. pIC50 transformation
6. Molecular fingerprint generation
7. Molecular descriptor generation
8. Scaffold-aware dataset partitioning
9. Classical machine-learning modelling
10. Hyperparameter optimization
11. Held-out evaluation
12. Molecular graph representation
13. Graph neural network evaluation
14. Diagnostic and residual analysis
15. Forensic methodological auditing

## Scientific limitations

The repository deliberately records methodological limitations identified
during the project audit. These limitations form part of the research record
and should be considered when interpreting the reported results.

## Provenance
